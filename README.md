# Pulse Code Modulation (PCM) – Virtual Lab

This project is a **web-based virtual laboratory experiment** designed to help students understand the principles of **Pulse Code Modulation (PCM)**, a fundamental technique used in digital communication systems.

The experiment visually demonstrates the effects of **sampling, quantization, and encoding** on analog signals.

---

Pulse Code Modulation (PCM) is a method used to digitally represent analog signals.  
It is widely used in:
- Digital telephony
- Audio CDs
- Computer audio systems
- Modern digital communication systems

The PCM process involves three main steps:
1. **Sampling** – Converting a continuous-time signal into discrete-time samples  
2. **Quantization** – Approximating each sample to the nearest discrete level  
3. **Encoding** – Representing quantized values in binary form
